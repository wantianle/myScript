# excel_tool

一个尽量少依赖第三方库的 Excel 小工具，当前只支持 `.xlsx`，基于 Python 标准库直接读写压缩 XML，兼容 Python `3.8+`。

现在只保留一个主流程：

- 先按表头同名，把源表同一行的数据复制到模板表。
- 如果需要，再在复制后的结果里按条件批量替换。
- 一次运行里可以连续配置多条替换规则。

## 最省事的用法

直接运行：

```bash
python3 excel_tool.py
```

脚本会按顺序问你：

- 源文件
- 目标模板文件
- 输出文件
- 要不要继续替换
- 如果要替换：可以给一条规则录多个筛选条件，也可以一次改多个列
- 每录完一条规则，还会问你要不要继续加下一条

如果当前目录里像你现在这样已经有：

- `集约化运作信息.xlsx`
- `集约化运作信息模板.xlsx`

它会自动把这两个文件作为默认值，你多数时候直接回车就行。

如果模板里有和源表同名的工作表，也会自动选中，不再额外问你。

## 命令行简化参数

如果你不想交互，也可以直接一条命令跑完。

只复制：

```bash
python3 excel_tool.py 集约化运作信息.xlsx 集约化运作信息模板.xlsx
```

复制后立刻替换：

```bash
python3 excel_tool.py 集约化运作信息.xlsx 集约化运作信息模板.xlsx \
  -w 应集约 \
  -e 是 \
  -s 实际集约 \
  -v 否
```

参数含义：

- `-w`：按哪一列筛选
- `-e`：筛选值等于什么
- `-s`：要改哪一列，省略时默认改 `-w` 那一列
- `-v`：改成什么值
- `-o` / `--out`：输出文件名

如果一条命令里要写多条规则，可以重复使用 `-r`：

```bash
python3 excel_tool.py 源.xlsx 目标.xlsx \
  -r "姓名|a|部门|待确认" \
  -r "状态|停用|姓名|离职"
```

`-r` 规则格式：

- `筛选列|筛选值|新值`
- `筛选列|筛选值|修改列|新值`
- `条件列=值&条件列2=值2=>更新列=值&更新列2=值2`

如果只写 3 段，就表示改筛选列本身。

多条件多更新示例：

```bash
python3 excel_tool.py 集约化运作信息.xlsx 集约化运作信息模板.xlsx \
  -r "所属省公司=广东-公司&客服专员.姓名=林琳=>客服专员.姓名=李晓莹&客服专员.账号=123456"
```

这个规则表示：

- 只处理 `所属省公司=广东-公司` 且 `客服专员.姓名=林琳` 的行
- 同时把 `客服专员.姓名` 改成 `李晓莹`
- 再把 `客服专员.账号` 改成 `123456`

可选高级参数：

```bash
python3 excel_tool.py 源.xlsx 目标.xlsx \
  --src-sheet 数据表 \
  --dst-sheet 模板表 \
  --header-row 1 \
  --start-row 2
```

## 说明

- 当前工具只处理普通数据表，不面向复杂公式、图表、透视表。
- 写回时优先保留原工作簿结构，但新写入的单元格不保证继承原格式。
- 默认输出文件名会自动带时间戳，避免重复覆盖旧结果。
- 对你现在这组样例文件，模板和源表有 52 个同名字段，`是否集约对账` 在源表里没有对应字段，所以会保留为空。
